# 号码罗盘

一个针对六合彩 `AMLHC_49` 的历史数据整理与多维候选分析工具。它读取每期 7 个 1-49 开奖号码，将频率、近期动量、遗漏回补、奇偶结构、和值与组合去重等信号合并展示，输出 9 个关注号码与 3 个强化号码。

## 运行

```bash
npm install
npm run dev
```

同步用户提供的网站历史数据：

```bash
npm run sync-history
```

同步脚本会请求网站的历史接口，并更新 `src/data/amlhc49-history.json`。当前已录入 229 期记录。

页面中的 URL 入口会尝试读取公开 HTML 页面；实际生产接入应通过后端代理完成抓取与字段解析，并在服务端接入合规的 AI API。当前版本使用本地演示样本，不保存或上传个人数据。

> 彩票结果具有随机性，预测仅用于数据研究与娱乐，不构成投注建议。
